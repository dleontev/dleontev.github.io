# Poppins

Latin WOFF2 subsets for weights 400, 500, 600, and 700, obtained from Google Fonts on 2026-09-12. The SIL Open Font License is in OFL.txt. Other characters use the system font fallback.

Fonts are served locally, use font-display: swap, and retain stable filenames across content updates. Rename the font files when replacing their bytes and update the CSS and preload together.
