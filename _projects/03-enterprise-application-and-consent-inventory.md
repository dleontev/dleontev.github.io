# Enterprise Application and Consent Inventory

**Status:** Planned

This project will demonstrate a structured review of Microsoft Entra enterprise applications and application registrations using sanitized or mock data.

## Planned scope

- Enterprise applications and service principals
- Application registrations and ownership
- Delegated and application permissions
- Admin consent and user consent
- Credential expiration and stale access
- Least-privilege review and follow-up documentation

The project will avoid publishing real application identifiers, tenant identifiers, secrets, certificates, user data, or production permission assignments.
